# Base de connaissances

Chaque fichier `.md` de ce dossier est lu par l'assistant avant de répondre.
L'assistant ne répond **qu'avec** ce qui est écrit ici.

- Un fichier par sujet (formations, admission, frais…).
- Écrire en français, phrases simples. L'assistant traduit lui-même en arabe.
- Mettre une date « Mis à jour le … » en haut de chaque fichier.
- Quand une information n'est pas encore confirmée par l'UCAB, l'écrire clairement (« à confirmer »).

Ce fichier README n'est pas envoyé à l'assistant.

État actuel : informations publiques (site ucab.sn, annuaires), en attendant les documents officiels de l'UCAB.
